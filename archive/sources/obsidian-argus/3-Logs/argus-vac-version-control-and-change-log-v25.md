## ⚙️ How to Version Documents & Software Files (RULE CHANGED 2026-08-25 by Justin)
1.  **Decimal bumps for small changes:** Edit the SAME file and bump its decimal version. Example: obstacle-detector v10 gets a small fix -> it becomes 10.1, then 10.2. Still one file.
2.  **Whole-version files for big changes only:** A major rewrite or architecture change creates ONE new file with the next whole version (10.x -> 11). The old file moves to _Archive/.
3.  **Log every bump:** Add a bullet under that file's history section in this change log with the date and what changed.
4.  **Registry sync:** Update the active version number in the Master Document Status Registry table above.
