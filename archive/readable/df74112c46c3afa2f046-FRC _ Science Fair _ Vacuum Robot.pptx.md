## ppt/slides/slide10.xml
Soldering Skills Improvement
Since I kept the soldering iron on the component for too long, it caused the plastic surrounding the metal contacts to melt. This results in the component becoming unusable, which wastes time and resources.
Plug a spare connector in
By plugging in a spare connector, it acts as a heat sink. The extra metal contacts mean that more heat is required to raise the temperature of the component, allowing me to keep the soldering iron on for longer.
Pre-tin 
both
 the connector and the wire
I used to 
only
 pre-tin the wire, which meant that there will be poor heat transfer
By tinning the connector too, the metal heats up way quicker
Heat shrink wrap

Main Takeaways From this Project
My biggest takeaway from this project is the concept of daisy chaining wires. Instead of running individual, redundant ground wires to every single component, daisy chaining made the circuit design more efficient.
Impact:
 Reduced cable clutter, minimized signal clutter, and reduced the risk of short circuits.

## ppt/slides/slide9.xml
QR Code Fix
To solve the issue of my QR code being too large, I utilized 4 main methods:
Setting Visual Dimension Limits
Set the QR code size to 256 by 256 px
Ensures the image size will not change
LZ-string Compression
Before any of the qr codes are generated, all the TSV(tab 
separated
 values) are compressed into Base64 format
E.g. A -> 000000, B -> 000001…
Character Sanitization
Newlines and tabs are deleted from text inputs to save space
Doesn’t this make the file size larger?
It does, but LZ string compression looks for 
recurring
 patterns and creates a dictionary for where the values should go
