The dashboard discovers new files automatically from the latest main commit.
Markdown is rendered, code is readable with line numbers, and explanations sit
below each file. It is a repository viewer, not live robot telemetry or control.

Record real-world validation separately from local tests and plans. Keep passwords,
private configurations, raw private chats and compiled firmware out of this public
repository. Commit reviewed source and documentation after meaningful changes.
